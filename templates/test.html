CampusPrinter

Version 1.0 — First Stable Release

Welcome to CampusPrinter

CampusPrinter is a campus printing management system designed to make printing simpler, faster, and more convenient for faculty and lab staff.

The first stable release is currently being tested with faculty members while the core printing infrastructure is being validated.

What's New

1. Easy Print Job Submission

Faculty can upload their documents and submit print jobs without manually transferring files to the lab computer.

2. Printer Selection

Faculty can select the required campus printer before submitting a print job. The system routes the job to the appropriate printer.

3. Secure Print Verification

Print jobs are protected using OTP-based verification. A verification code is sent to the faculty member's registered email before the document can be released for printing.

4. Lab-Based Print Agents

Each connected lab printer is managed through a dedicated CampusPrinter Print Agent running on the lab computer.

5. Printer Health Monitoring

The system can check whether a Print Agent is reachable and maintain the current availability status of connected printers.

6. Lab Incharge Controls

Lab in-charges can control printer availability and manage printing permissions through the Lab Incharge Dashboard.

7. Print Job Cancellation

Pending print jobs can be cancelled before they are released to the physical printer.

8. Multiple Printer Support

CampusPrinter is designed to support multiple printers across different labs and blocks from a single centralized system.

9. Secure File Handling

Print documents are transferred to the Print Agent using encrypted file data rather than sending the original document directly to the lab computer.

10. Automated Printing

Once a print job is verified, the Print Agent automatically processes the document and sends it to the connected printer.

How CampusPrinter Works

  1. Faculty member logs into CampusPrinter.
  2. Faculty member selects a printer.
  3. Faculty member uploads the document.
  4. The print job is securely transferred to the selected lab.
  5. An OTP is sent to the registered email.
  6. The faculty member reaches the lab and enters the OTP.
  7. The Print Agent releases the document.
  8. The connected physical printer prints the document.
